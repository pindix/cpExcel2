nome não está na base, erro.
se o nome está numa das bases, deve aparecer os seus campos respectivos.
se o elemento não contém nota (nota=""), a nota não é exibida
se não contém estado, o estado não é exibido.
}

sugestões {
o label do primeiro campo vai ser: Exame, Doença ou Escala 
se o nome for dos diagnóstico, mudamos o lable do primeiro campo para diagnóstico,

}

explicação. a ideia é dar flexibilidade ao sistema. podemos usar uma mistura de campos para 
atender as necessidades de forma mais precisa. se um elemento só precisa de um campo, vamos colocar só um campo.
